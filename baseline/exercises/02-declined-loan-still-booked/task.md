# 02｜已婉拒的貸款申請仍然入帳

- 難度：★☆☆☆☆
- 回報單位：授信風險管理部

## 現象

同一客戶、同一幣別的未結清本金合計不得超過 5,000,000（`mini-cob.customer-exposure-limit`）。超過上限的申請，API 會回 `422`，訊息是「exposure ... would exceed the limit」，前台也通知客戶申請未核准。

月底風管對帳時卻發現，這些被婉拒的客戶名下多了一筆貸款。金額正好是被婉拒的那筆，而且帳號是空的。

## 重現方式

1. 客戶 `C-EX02` 已有一筆 4,000,000 TWD 的貸款。
2. 用 `POST /api/loans` 再替 `C-EX02` 申請 2,000,000 TWD → 收到 422。
3. 查詢 `C-EX02` 名下的貸款。

## 期望行為

被婉拒的申請不能產生任何貸款資料。`C-EX02` 名下只能有原本那一筆 4,000,000 的貸款。

./mvnw test -Dtest=Ex02DeclinedLoanApplicationTest
