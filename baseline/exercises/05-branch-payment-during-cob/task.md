# 05｜COB 期間分行入帳，該筆貸款當天沒有關帳

- 難度：★★★★☆
- 回報單位：營運部

## 現象

有些分行系統直接寫入核心帳務，不經過本服務的還款 API，因此不會被 COB 的帳戶鎖擋下。偶爾會有一筆分行的本金入帳，恰好在 COB 處理同一筆貸款時提交。

這種情況發生的晚上，那筆貸款當天都沒有關帳，批次報表也顯示「skipped: 1」。系統明明設定了版本衝突時要重試，但看起來重試沒有發揮作用。

## 重現方式

測試裡有一個只存在於測試程式碼的 COB 步驟（`TellerActivitySimulator`）。它會在 COB 第一次處理指定貸款時，用另一條資料庫連線替該貸款入帳一筆本金並立即提交，藉此穩定重現「分行剛好在 COB 處理中入帳」的時間點。

1. 建立一筆本金 100,000 TWD、年利率 7.3% 的貸款。
2. 讓分行在 COB 處理期間入帳 10,000 元本金。
3. 執行營業日 2026-04-16 的 COB。

## 期望行為

- 該筆貸款當天正常關帳（`last_closed_business_date = 2026-04-16`），沒有被跳過。
- 分行的入帳被保留：未償本金為 90,000。
- 利息以 90,000 計算：90,000 × 7.3% / 365 = 18。
