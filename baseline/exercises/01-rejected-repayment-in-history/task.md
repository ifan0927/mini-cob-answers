# 01｜被拒絕的還款出現在還款明細裡

- 難度：★★☆☆☆
- 回報單位：客服部

## 現象

客戶在網銀輸入的還款金額大於貸款的全部應還金額。API 回應 `422 Unprocessable Entity`，畫面也顯示「還款失敗」。

可是客服查詢這筆貸款的還款明細（`GET /api/loans/{id}/repayments`）時，明細裡卻多了一筆金額相同的還款紀錄。貸款餘額沒有變動。客戶以為錢已經扣了，打電話來詢問。

## 重現方式

1. 建立一筆本金 100,000 TWD、尚未產生利息的貸款。
2. 以任一冪等鍵送出 100,001 元的還款 → 收到 422。
3. 查詢該貸款的還款明細。

## 期望行為

API 回覆失敗的還款不能留下任何痕跡：還款明細必須是空的，貸款狀態也維持不變。
