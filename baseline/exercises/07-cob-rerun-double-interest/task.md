# 07｜同一營業日重跑 COB，利息被計了兩次

- 難度：★★☆☆☆
- 回報單位：營運部

## 現象

標準作業程序規定：COB 部分失敗時，先修好資料，再對同一個營業日重跑一次（`POST /api/cob/runs?cobDate=...`）。重跑只應該處理上次沒處理完的貸款。

上週依照程序重跑之後，客戶來電抱怨利息多算了一天。查帳發現所有貸款當天都有兩筆利息提列，連第一次就已經成功關帳的貸款也一樣。

## 重現方式

1. 建立 3 筆本金 100,000 TWD、年利率 7.3% 的貸款。
2. 執行營業日 2026-04-16 的 COB，成功。
3. 再次執行營業日 2026-04-16 的 COB，成功。

## 期望行為

重跑不能影響已經關帳的貸款。每筆貸款的應計利息仍是一天的 20，`INTEREST_ACCRUAL` 交易也只有一筆。

./mvnw test -Dtest=Ex07CobRerunTest
