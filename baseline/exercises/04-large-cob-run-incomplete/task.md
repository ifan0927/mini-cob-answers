# 04｜貸款量一大，COB 就漏處理或重複處理

- 難度：★★★★☆
- 回報單位：財務部

## 現象

上線第一個月，帳上的有效貸款大約幾百筆。財務每天核對利息時發現：

- 有一大批貸款當天沒有關帳（`last_closed_business_date` 沒有前進），也沒有利息。
- 少數貸款在同一天被計了不只一次利息。
- 每晚出問題的貸款都不一樣。

QA 在測試環境用十幾筆資料怎麼跑都正常，無法重現。

## 重現方式

1. 建立 400 筆貸款：200 筆年利率 7.3%（每日利息 20），200 筆年利率 10.95%（每日利息 30）。
2. 執行營業日 2026-04-16 的 COB。

## 期望行為

每一筆貸款都恰好被關帳一次：`last_closed_business_date = 2026-04-16`，利息正確，而且每筆只有一筆 `INTEREST_ACCRUAL` 交易。
